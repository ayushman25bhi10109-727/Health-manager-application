Health Manager - Console-Based Health Tracking Application
A comprehensive Python-based console application designed to help users track their health and fitness journey through efficient meal and exercise logging. This robust system combines simplicity with powerful tracking capabilities, making health management accessible to everyone.

Features
 User Management System
Secure user registration and login functionality

Individual data isolation with separate user files

Session management for multiple users

 Health Tracking
Meal Logging: Record food consumption with calorie information and timestamps

Exercise Monitoring: Track workouts with duration and calories burned

Flexible Timestamps: Automatic current time or custom date/time entries

Data Validation: Input validation for numerical data and required fields

 Analytics & Reporting
Comprehensive Record Views: Browse complete history of meals and exercises

Calorie Analysis: Net calorie calculation (intake vs burned)

Progress Summaries: Total calories, duration, and activity counts

Sorted Records: Chronological organization with newest entries first

 Data Management
JSON Storage: Structured data storage using human-readable JSON files

Persistent Data: All records maintained between application sessions

Backup-Friendly: Easy to export, backup, and restore user data

File-based System: No database required - uses local text files

 User Experience
Clean Console Interface: Intuitive menu-driven navigation

Input Validation: Robust error handling and user feedback

Session Persistence: Maintains login state during use

Cross-Platform: Works on Windows, Linux, and macOS

Technical Implementation
Built entirely in Python using core programming concepts:

File I/O operations for data persistence

JSON serialization for structured data storage

DateTime handling for accurate timestamping

Object-oriented design with modular architecture

Console-based user interface with menu navigation

Ideal For
Individuals wanting to monitor daily calorie intake and expenditure

Fitness enthusiasts tracking workout consistency and progress

People developing nutritional awareness and healthier habits

Python learners studying file handling and console applications

Anyone seeking offline health tracking without subscription fees

Getting Started
Run the Python script

Register a new user account or login

Start logging meals and exercises

View your progress through comprehensive summaries

Maintain your health journey with persistent data storage

Privacy & Security
All data stored locally on your machine

No internet connection required

Individual user file isolation

No sensitive personal information collected

Take control of your health and fitness with this powerful, privacy-focused tracking solution that puts your data securely in your hands.
